## Design Context

### Users

Kinfolk is for relatives building a shared family record together, often in short sessions
on a phone and in longer research sessions on a desktop. They should be able to add a
parent, partner, child, sibling, or social connection without learning the graph schema.

### Brand Personality

Warm, trustworthy, archival. The product should feel like a carefully kept family album
with the clarity of a contemporary tool, not a genealogy database or a social feed.

### Aesthetic Direction

Canvas-first and organic, using the existing paper, ink, evergreen, and restrained amber
palette in both light and dark themes. Quiet structure, compact controls, and generous
reading space should keep the family itself visually dominant.

### Design Principles

1. Select a person, then act on that branch.
2. Relationship words lead; database concepts stay behind the interface.
3. Private by default, with every wider audience requiring an explicit decision.
4. Mobile keeps every core action within thumb reach rather than hiding functionality.
5. One deployment: components assume the Next server runtime (server actions, cookies), never a static host.
