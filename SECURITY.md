# Security policy

## Supported version

Security fixes are applied to the latest release on `main`, currently 0.3.x. Older releases are not supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting form:

<https://github.com/Sagargupta16/kinfolk/security/advisories/new>

If GitHub does not show that form, open only a content-free issue asking for a private contact method. Do not include vulnerability details in the issue.

Include the affected route or component, reproduction steps, impact, and any suggested mitigation. Use synthetic records only; do not attach real family data, credentials, session tokens, environment files, or database exports.

You should receive an acknowledgement within 3 business days. Please allow time for a fix and deployment before public disclosure.

## Scope

Reports about authentication, authorization, cross-tree data access, contact visibility, OAuth redirects, session handling, secret exposure, and dependency vulnerabilities are in scope. General feature requests belong in the issue tracker.
